Мои настройки bash

## Структура

Перевёл проект на модульную структуру.

```
.
├── .bash_aliases
├── .bash_colors
└── .bashrc

```

- `.bash_aliases` — псевдонимы (alias), вынесенные в отдельный файл
- `.bash_colors` — список цветов консоли, вынесенных в переменные
- `.bashrc`
